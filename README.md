# sql-business-analysis
SQL-based analysis of e-commerce sales data to answer practical business questions.
## 🔑 SQL Concepts Used

- SELECT
- WHERE
- COUNT
- SUM
- AVG
- GROUP BY
- ORDER BY
- Aggregate Functions
- Business-oriented SQL analysis

## 📊 Business Questions

This project answers questions related to:

- Total orders
- Product revenue
- Customer spending
- Category revenue
- Category sales quantity
- Monthly revenue
- Customer order frequency
- Average order value
- Product quantity sold
- Overall revenue
## 💡 Key Insights

The analysis can be used to identify:

- Products generating the highest revenue
- Customers with the highest spending
- Categories generating the most revenue
- Monthly revenue patterns
- Products with the highest sales volume
- Customer ordering behavior
- Overall business revenue
